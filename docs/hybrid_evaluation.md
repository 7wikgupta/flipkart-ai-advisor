Generated by `python scripts/hybrid_eval.py` on the Phase 2 index (flipkart_electronics_v1). Semantic search is the Phase 2 baseline. Hybrid fuses it with BM25 keyword search (k1=1.5, b=0.75) by Reciprocal Rank Fusion (k=60) over the top 20 products of each. No LLM is involved.

**Decision rule, fixed before running:** adopt hybrid if named-product MRR improves, at most one category hit is lost across both category tests, median latency rises by under 50 ms, budgets hold and no off-topic question scores higher than with semantic search (the evidence gate must behave the same).
